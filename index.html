L'Art du Mouvement

Chaque particule que vous voyez est générée mathématiquement, flottant dans un vide simulé. Le parallaxe ici n'est pas qu'une illusion de profondeur, c'est une invitation à ralentir votre lecture pour observer le décalage des strates numériques.

Ce projet utilise Canvas API pour la performance et des calculs de scroll-offset personnalisés pour la fluidité.
